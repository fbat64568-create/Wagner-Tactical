# Wagner Tactical Aviation — Demonstration Website

A static, responsive, cinematic aviation/evacuation website concept.

## Important
This project is intentionally positioned as a **fictional demonstration concept**. It does not represent, impersonate, or claim affiliation with Wagner Group, the Russian government, Russian Armed Forces, or any military organization.

The site does not offer weapons, combat operations, mercenary recruitment, military deployment, armed-security contracts, or offensive services.

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, and `README.md`.
3. In GitHub: Settings → Pages → deploy from the `main` branch/root.

## Deploy to Netlify
Drag the project folder into Netlify Drop, or connect the GitHub repository. No build command is required.

## Notes
- The dashboard is simulated UI only.
- The contact form intentionally does not transmit data; it displays a local demo confirmation.
- Hero/about photography is loaded from Unsplash URLs, so internet access is needed for those images.
- The uploaded emblem was not used because it closely resembles a real-world Wagner-related insignia; the site instead uses a neutral fictional aviation mark.
